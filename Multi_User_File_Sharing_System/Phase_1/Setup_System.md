## 遇到的问题
| 阶段                | 问题                           | 原因                                       | 最终解决方案                                         |
| ----------------- | ---------------------------- | ---------------------------------------- | ----------------------------------------------------- |
| **1. 制作安装U盘**   | U盘无法被迷你主机BIOS识别                | U 盘制作方式或启动模式（UEFI/Legacy）不匹配             | 不用GNU DD制作，用balenaEtcher制作   |
| **2. USB 外设**     | 三个 USB 设备同时插入主机无法识别          | 不明                           | 只插两个莫名其妙好了                                      |
| **3. Debian 安装**  | 不小心安装成 GNOME 桌面版             | 安装时选择了 Desktop Environment               | 后续卸载 GNOME，仅保留 SSH 和命令行环境         |
| **4. PATH 疑似异常**  | `modprobe`、`modinfo` 提示找不到   | 普通用户 PATH 默认不包含 `/usr/sbin`              | 确认这是 Debian 默认行为，不是系统故障         |
| **5. Wi-Fi 掉线现象** | 拔掉USB键盘后Wi-Fi稳定断开         | 不明，可能是系统与无线网卡兼容性问题 | 使用 `nmcli radio wifi off` 禁用无线电，仅保留有线网络          |

## 经验
- 除了不要再晚上刷机，还不要晚上装Linux，会遇到很多意想不到的问题并且熬穿也未必能修好。
- 优先使用有线网络，不要把服务器建立在Wi-Fi的稳定性上。
- 排查问题时先确认硬件，再怀疑软件，不要一开始就认为系统坏了。
- 很多看起来像 Bug 的现象，其实只是 Debian 的默认设计（例如普通用户 PATH）。
